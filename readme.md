# Fandromeda Engine
Cosmic Fantasy Analytics & Waiver Intelligence Hub

## Quick Start
1. Run roster sync: `python import_roster.py`
2. Generate dashboard: `python index.py`

## Features
* **Positional WOPR & Opportunity Scores:** Tailored metric models per position.
* **Verdict Engine:** Automatically tags *Buy Low*, *Fluke Risk*, and *Surging Role*.
* **Interactive Dashboard:** Filter by team, click headers to sort, click names for game logs.

## Security Note
Keep API credentials out of tracking. Ensure `.env` is listed in `.gitignore`.
